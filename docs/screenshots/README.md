## How the Screenshots Were Made

Captured on 2026-10-18 from the actual **smoke-test** set through read-only Exif
Turbo MCP calls, with real Ollama suggestions. The capture used an isolated local
review and refused metadata-writing MCP tools and Apply/reset commands. It did not
change the original files, save sidecar edits, reset user progress or change saved
service settings. Tag-removal and description-exclusion examples are local drafts.

The selected castle sample contains an embedded caption but no embedded keywords;
the keyword screenshot therefore shows its real empty state. No embedded metadata
was invented to populate the interface. The Settings screenshot shows standard
example localhost URLs in place of saved private addresses, and directory/source-file
fields are omitted from the Metadata capture. Settings and approval captures are
cropped to their dialogs; the other captures show the application window.

Sources and licence records were checked against the upstream Exif Turbo manifest
and the linked Wikimedia Commons file pages on 2026-10-18. No endorsement by either
photographer, Wikimedia Commons, or the upstream project is implied.
